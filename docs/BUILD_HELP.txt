┌──────────────────────────────────────────────────────────────────┐
│  🛠️  Troubleshooting                                             │
└──────────────────────────────────────────────────────────────────┘

  Problem: Build too slow or timing out
  ─────────────────────────────────────
  Solution:
  1. Open Docker Desktop
  2. Settings → Resources
  3. Set Memory to 8GB (minimum)
  4. Set CPUs to 4-6 cores
  5. Apply & Restart

  Problem: Build appears stuck
  ─────────────────────────────────────
  Solution:
  1. Check Docker Desktop CPU usage
  2. If CPU is active, just wait
  3. If no activity, try Dockerfile.fast:
     $ cd api
     $ docker build -f Dockerfile.fast -t face-api .

  Problem: Out of memory errors
  ─────────────────────────────────────
  Solution:
  1. Close other applications
  2. Increase Docker memory to 8GB
  3. Use Dockerfile.fast (uses less memory)
